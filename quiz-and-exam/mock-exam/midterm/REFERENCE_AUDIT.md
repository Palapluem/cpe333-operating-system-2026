### สิ่งที่ไม่ใช่การคัดคำต่อคำ

ปี 2561 ต้นฉบับกำหนด Mark all the correct choices จึงต้องเลือก/ปรับตัวเลือกให้เป็น single-answer ตามคำขอ ไม่ใช้ All of the above หรือ Both a and b

คำถามหลายข้อคงแนวและสาระของต้นฉบับ แต่ปรับ grammar, qualifier และตัวเลือก เช่น conventional stack layout, successful exec, legal/not-present page, non-preemptive FIFO และ fixed page/PTE size เพื่อปิดความกำกวม

ตัวอย่างคำตอบกำกับในชุด 2022 ที่ไม่คัดตาม: ข้อ 6 หน้าสรุประบุ timer ทั้งที่ถาม non-preemptive แต่ภาพหน้า 3 ระบุ None; ข้อ 9 หน้าสรุปกล่าว ready เปลี่ยนตรงเป็น blocked เมื่ออ่านไฟล์ ทั้งที่ภาพระบุ Cannot happen; ข้อ 20 หน้าสรุประบุ None ทั้งที่ fixed-size partition มี internal fragmentation ตัวเลือกที่ถูกจึงตรวจด้วย Lecture ไม่ใช้ annotation เป็นเฉลยอัตโนมัติ

## ส่วนที่ 2: คำตอบสั้นจริง

ทวน E10 หน้า 1–3 โดยคงเฉพาะ Lecture 1–6 ไม่ดึง threads, critical sections, semaphore หรือ deadlock มาปน คำถามในฉบับนี้ปรับให้คำตอบตัวอย่างจบใน 1–2 บรรทัด ส่วนใหญ่ 1 บรรทัด ไม่ใช่ย่อหน้าอธิบาย

- ข้อ 1, 3, 10: ชื่อเต็ม MLFQ/STCF, MMU และ TLB; ข้อ 3/10 เพิ่มหน้าที่หรือเหตุผลสั้นเพียงใจความเดียว
- ข้อ 2: process เทียบ program เพียงประโยคเดียว
- ข้อ 4–5: ตัวอย่าง CPU state 2 อย่าง / ข้อมูล PCB 2 ประเภท ไม่ถามขั้นตอนหรือชื่อเต็มเพิ่ม
- ข้อ 6: keyword zombie ก็ได้เต็มคะแนน ไม่บังคับเหตุผลที่ไม่ได้ถาม
- ข้อ 7: ตัวอย่างงาน I/O-bound และ CPU-bound อย่างละ 1 งาน เป็นการปรับรูปคำถามจาก E10 Q15 ไม่ใช่การคัดตรง
- ข้อ 8–9: เหตุผลของ LJF / ตรวจ bounds อย่างละ 1 ประโยค ไม่ต้องแสดงวิธีทำยาว

คงช่องว่าง 0.90 ซม. ต่อข้อ ทั้ง 10 ข้ออยู่หน้า 9 ไม่มีคำตอบ/keyword ตัวอย่างพิมพ์ลงในตัวข้อสอบ เฉลยแยกและ rubric ไม่บังคับรายละเอียดนอกคำถาม การตรวจความยาวใช้คำตอบตัวอย่าง ไม่บังคับผู้สอบใช้ถ้อยคำเดียวกัน

## ข้อเขียน 3: Page Replacement / EAT

ต้นฉบับ: E05 หน้า 2 (Midterm 1/2022 – Part 2.2)

| รายการในต้นฉบับ | ตรวจในฉบับนี้ |
|---|---|
| 3 physical frames | ครบ |
| Separate tables: FIFO, LRU, OPT | ครบ แก้ typo “both policies” เป็นแต่ละ policy เพราะมี 3 วิธี |
| Reference string 20 ตัว | ตรงทุกตัว |
| 7,0,1,3,0,3,2,4,2,7,0,3,2,1,2,0,1,4,0,1 | ครบ |
| EAT ของแต่ละ policy | ครบ |
| Memory access = 10 ns | ครบ |
| Disk access = 10 ms | ครบ |

ระบุเพิ่มเติมว่า frames เริ่มว่าง ให้แสดง hit/fault, counts และ probability เพื่อเห็นขั้นตอน และกำหนดให้ 10 ms เป็น complete fault-path cost รวม restart เพื่อให้ EAT มีโมเดลชัดเจน ไม่ใช่การอ้างว่าต้นฉบับระบุสมมติฐานนี้ไว้แล้ว คะแนนเปลี่ยนจาก 13 เป็น 8 ตามคำขอ

รอบจัดระเบียบแบ่งงานเดิมเป็น (a) ตาราง FIFO/LRU/OPT พร้อม hit/fault 4.5 คะแนน, (b) จำนวน faults/hits และ fault probability 1.5 คะแนน, (c) EAT หน่วย ms 2 คะแนน ไม่มีการเปลี่ยน reference string หรือสมมติฐาน เฉลยและ rubric ใช้ป้าย (a)–(c) ตรงกัน

ผลตรวจคำนวณยังเป็น FIFO/LRU/OPT faults = 13/13/10; ไม่คัดตัวเลขหน่วยเวลาที่เขียนกำกับผิดในต้นฉบับ

## สรุปความตรงต้นฉบับ

ไม่มีข้อมูลสำคัญหรือคำถามย่อยของสามข้อที่ตกหล่น แต่เป็นฉบับคัดและปรับสำหรับข้อสอบฝึก ไม่ใช่ facsimile คำต่อคำ คะแนนย่อย/สมมติฐานที่เพิ่มอธิบายไว้ข้างต้น แยกชัดเจนจากข้อมูลเดิม
